A full-stack healthcare compliance dashboard for correctional facilities.

## Technologies

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- HTML
- CSS
- JavaScript

## Features

- Facility dashboard
- State and county filtering
- Compliance check management
- Add, edit, and delete compliance records
- REST API integration
- PostgreSQL database connectivity
- Swagger API documentation
